# Developer Portfolio

Proyecto de portfolio para desarrollador usando Next.js 14 con App Router.

## Estructura del Proyecto

```
app/
├── layout.tsx          # Layout principal
├── page.tsx           # Homepage
├── globals.css        # Estilos globales
├── about/
│   └── page.tsx       # Página About
└── blog/
    ├── page.tsx       # Lista de posts del blog
    └── [slug]/
        └── page.tsx   # Página individual de post
```

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```
